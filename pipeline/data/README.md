# Данные pipeline

В репозитории хранится только `sample.csv` как схема итоговой выгрузки.

Не храним в Git:

- видео;
- `db_hack.csv`;
- обучающие разметки;
- сгенерированные датасеты;
- веса моделей.

Это сделано специально: такие файлы тяжёлые, могут относиться к условиям хакатона или внутренним данным заказчика и должны подключаться как внешние артефакты.
